Tabs missing? Enable Allow User Scripts in Tampermonkey’s extension settings if available.

Questions

Is Better HUD free?

Yes. Free and open source under the MIT license.

Which browsers work?

Desktop Chrome, Edge, Firefox and Opera GX with Tampermonkey.

Where are my stats saved?

In your browser. You can export them anytime.

How do I change a setting back?

In MODS, use Reset on any changed setting.
